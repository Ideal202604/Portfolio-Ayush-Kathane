# Ayush Kathane — Portfolio

A personal portfolio built to feel alive which shows Law student pursuing a career in corporate law with a focus on mergers & acquisitions, private equity, and risk management. Aspiring in-house counsel, building a strong foundation in transaction structuring, due diligence, and strategic legal advisory.
---

## What Makes It Stand Out

- Scroll animations that actually feel smooth, not janky
- Clean, distraction-free design that puts the work front and center
- Loads fast. Really fast.
- Looks great on phone, tablet, and desktop
- Every interaction has a little something to it — nothing feels dead

---

## Tech Stack

| What | Why |
|---|---|
| React 19 + TypeScript | The core — modern, fast, and fully typed |
| Vite 6 | Builds in seconds, dev server is instant |
| Tailwind CSS 4 | Styling done right — no bloat, pure utility |
| GSAP + ScrollTrigger + `@gsap/react` | The engine behind all the scroll magic |
| Motion (`motion/react`) | Declarative animations for React components |
| Lucide React | Clean, minimal icon set |
| Vercel | Deployed and live in seconds |

---

## Running Locally

```bash
git clone https://github.com/ayushkathane/portfolio.git
cd portfolio
npm install
npm run dev
```

That's it. Opens at `http://localhost:5173`.

---

## Deploy

Deployed on Vercel. Push to `main` and it goes live automatically. No extra setup needed.
